# GameVerse

GameVerse is a web-based gaming hub that brings games from multiple platforms together in one place. Instead of searching across different websites and launchers, users can discover games, view game information, and access authentic links to their official platforms. The project also includes browser-based games that can be played directly without downloading or installing anything.

The goal of GameVerse is to make game discovery simple, fast, and reliable. It provides a clean and user-friendly interface where players can search, browse, and explore games by category or platform. By connecting users to official sources, GameVerse helps them avoid unreliable websites while saving time.

## Features

* 🎮 Browse games from multiple platforms in one place.
* 🔍 Search and filter games by category or platform.
* 🔗 Access authentic links to official game stores and websites.
* 🕹️ Play browser games directly on the website.
* 📱 Responsive design for desktop, tablet, and mobile devices.
* ⚡ Simple, fast, and easy-to-use interface.

## Tech Stack

* HTML5
* CSS3 

## Project Goal

GameVerse aims to provide a centralized platform where gamers can easily discover, explore, and access their favorite games without the hassle of visiting multiple websites. It combines convenience, security, and a better user experience into a single gaming hub.
